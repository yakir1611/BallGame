# BallGame

## Overview
In this project we built the Arkanoid game on top of the GUI library provided by Bar-Ilan University.
It was an assignment in the Object-Oriented Programming course at Bar-Ilan University.

## User Guide
The goal is to eliminate all the blocks on the screen.
Every time the ball hits a block, the block disappears, the player gets 5 points, and the ball changes its color to the color of the block it hit.
You control the ball by moving the paddle at the bottom of the screen with the left and right arrow keys.

## Run
First, clone the repo. Then run the following commands inside the project folder:
* Compile the program: `ant compile`
* Run the program: `ant run`

## Requirements
* Java
* Ant
